# Documento A — Procedimiento de acceso temporal

Para solicitar acceso temporal a un repositorio interno:

1. abrir una solicitud en el portal de soporte;
2. indicar repositorio, motivo y duración;
3. obtener aprobación del responsable del recurso;
4. limitar el permiso al mínimo necesario;
5. retirar el acceso al finalizar el periodo autorizado.

# Documento C — Política de revisión

Las solicitudes de acceso privilegiado requieren aprobación humana y deben quedar registradas.
No se permite que un asistente de IA otorgue permisos directamente.
