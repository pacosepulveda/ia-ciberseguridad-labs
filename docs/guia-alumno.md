# Guía del alumno

## Cómo trabajar con los laboratorios

Estas prácticas están pensadas para realizarse directamente desde el navegador. No necesitas instalar herramientas de seguridad ni disponer de licencias de Microsoft Security Copilot, Gemini en Google SecOps u otras plataformas empresariales.

Para cada laboratorio tendrás:

- un escenario;
- uno o varios artefactos para analizar;
- una serie de tareas;
- una plantilla de entrega;
- criterios para verificar la respuesta generada por la IA.

## Regla principal

No aceptes una respuesta del modelo solo porque parezca convincente. Separa siempre:

- **hechos observables** en el artefacto;
- **inferencias razonables**;
- **suposiciones no verificadas**.

## Flujo recomendado

1. Lee primero el escenario y el artefacto sin usar IA.
2. Anota qué elementos te parecen relevantes.
3. Pide al LLM que analice el material siguiendo la plantilla indicada.
4. Compara su respuesta con el artefacto original.
5. Corrige al modelo cuando invente datos, exagere la certeza o ignore evidencias.
6. Entrega una conclusión breve y justificada.

## Uso responsable

Los ejemplos del repositorio son sintéticos y están creados para formación. No introduzcas en servicios públicos de IA credenciales, información confidencial, datos personales reales, secretos empresariales ni artefactos procedentes de incidentes reales sin autorización expresa de tu organización.
