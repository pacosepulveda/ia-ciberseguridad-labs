# Recursos del curso

Esta carpeta reúne referencias que complementan los laboratorios sin exigir licencias empresariales.

Se priorizarán recursos gratuitos y accesibles desde navegador relacionados con:

- MITRE ATT&CK;
- Sigma;
- YARA;
- OWASP para aplicaciones con LLM e IA generativa;
- documentación pública de proveedores;
- datasets y ejemplos sintéticos de seguridad;
- guías de uso responsable y gobernanza de IA.

Microsoft Security Copilot y Gemini en Google SecOps pueden aparecer como referencias conceptuales del mercado, pero no forman parte de los requisitos prácticos del curso.
