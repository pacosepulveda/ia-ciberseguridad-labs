# Prompts reutilizables

Esta carpeta contiene plantillas de prompting para las prácticas del curso.

Principios comunes:

- pedir al modelo que distinga hechos, inferencias y dudas;
- exigir referencias al artefacto original;
- evitar conclusiones categóricas cuando faltan evidencias;
- solicitar una salida estructurada y fácil de revisar;
- usar la IA como apoyo al analista, no como autoridad final.
