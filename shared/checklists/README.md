# Checklists

Checklists de apoyo para revisar las respuestas generadas por IA durante las prácticas.

## Checklist mínima de verificación

Antes de aceptar una conclusión generada por un LLM:

- [ ] ¿La afirmación aparece respaldada por una evidencia concreta?
- [ ] ¿El modelo ha inventado indicadores, nombres, fechas o eventos?
- [ ] ¿Ha confundido correlación con causalidad?
- [ ] ¿Distingue correctamente hechos de inferencias?
- [ ] ¿Expresa el nivel de confianza de forma razonable?
- [ ] ¿Propone datos adicionales que ayudarían a confirmar o descartar la hipótesis?
- [ ] ¿La recomendación es proporcional al riesgo observado?
